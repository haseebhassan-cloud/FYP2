# UR5 Human-Robot Collaboration (HRC) Reinforcement Learning Simulation

This repository contains a high-fidelity Deep Q-Network (DQN) framework implemented in PyTorch, integrated with a physics-informed MuJoCo workspace to optimize industrial safety buffers and velocity tracking for a UR5 manipulator.

## 🛠️ Prerequisites & Setup

Ensure you have Python 3.10 or 3.11 installed. It is highly recommended to run this in a clean virtual environment or an Anaconda environment.

1. **Clone or download** this repository to your local machine.
2. **Open your terminal/command prompt** and navigate to the project directory.
3. **Install the dependencies** by executing:
```bash
   pip install -r requirements.txt
